# Hazarot – Substitution Planner

A small toolkit to build a **substitution plan** for book questions using unassigned candidate questions, plus a helper to parse raw reports into a clean, searchable table.

The core logic lives in `substitutions/substitutions.py`. It loads CSVs, computes per-container target levels, and proposes replacements that best match difficulty—while honoring business rules (special Hebrew subjects, removed containers, one-time usage, etc.). Results are exported as an Excel‑friendly UTF‑8 BOM CSV.

## Features

- **Difficulty‑aware substitution** – For each book question, pick the best unassigned candidate (closest level to target).
- **Respect special subjects** – Questions whose subject is `הסקה מתרשים` are never substituted.
- **Skip removed containers** – If a book question belongs to a container listed in `containers_to_be_removed.csv`, it’s omitted from the plan. Non‑book questions from those containers **do** join the candidate pool.
- **One‑time use** – A candidate question can be used at most once.
- **Average impact** – The plan includes `avg_delta`: the signed change to the container average if the swap occurs (rounded to 2 decimals).
- **Robust IDs + Hebrew‑friendly CSVs** – Handles `123` vs `123.0`, stray BOMs, headerless CSVs. Exports with `utf‑8‑sig`.

1. Place your CSVs in `substitutions/`:
   - `book_qusetions.csv`  *(yes, the original misspelling is preserved)*
   - `containers_questions.csv`
   - `assignments_containers.csv`
   - *(optional)* `containers_to_be_removed.csv`

2. Run the tool:
```bash
cd substitutions
python substitutions.py
```

Outputs:
- `substitution_plan.csv` — the plan
- A short console summary (how many substitutions, how many removed containers loaded)

## Input files / schemas

Only a **few columns** are required. Headers can be changed centrally via `SCHEMA` in `substitutions.py`.

### `book_qusetions.csv`
| Column            | Meaning                           |
|-------------------|-----------------------------------|
| `q_id`            | Book question ID (string/int)     |
| `missing in book` | 1 means “missing”, exclude        |

### `containers_questions.csv`
| Column                  | Meaning                                          |
|-------------------------|--------------------------------------------------|
| `Question ID`           | Question ID                                      |
| `Container ID`          | Non‑zero container means “assigned”              |
| `Question Level`        | Numeric difficulty                               |
| `Question (Main) Tag`   | Subject (Hebrew/English)                         |
| `Question Active`       | 1 / "yes" / "true" → active                  |

> **Notes**
> - IDs like `62616.0` are normalized to `62616` internally.
> - Subject is matched in lowercase (Hebrew supported).

### `assignments_containers.csv`
Currently loaded for parity with older pipelines; the logic reads assignments from `containers_questions.csv`.

### `containers_to_be_removed.csv` (optional)
List of container IDs to omit from the plan. The loader is tolerant to:
- With or without a header
- UTF‑8 BOM on the first value
- A single value in the file

**Examples**

Headerless:
```
62616
62620
```
With header:
```csv
Container ID
62616
62620
```

## Output files

### `substitution_plan.csv`
Columns:
- `container_id` – canonicalized (e.g., `62616`, not `62616.0`)
- `old_question_id` – original book question ID
- `new_question_id` – chosen candidate ID (blank if not substituted)
- `no_substitute_in_subject` – original subject when we had to pick outside the subject (otherwise blank)
- `avg_delta` – signed change to container average if the swap happens (e.g., `+0.12`, `-0.08`)

---

## How the algorithm works

For each eligible book question (non‑missing):

1. **If subject is `הסקה מתרשים` →** never substitute.  
2. **If its container is listed in `containers_to_be_removed.csv` →** skip entirely (no row).  
3. Compute **target level**: container’s average (active rows) → the question’s own level → global median of candidate levels.  
4. Build a **candidate pool** of unassigned questions **plus** questions from removed containers (active‑only if requested); exclude any ID that already appears in the book.  
5. **Pick** the unused candidate minimizing `|level - target|`, preferring **same subject**.  
6. Mark the candidate as used (one‑time).  
7. Compute `avg_delta = (new_level - old_level) / N`, where `N` is the count of items in the container average.

All ID fields are normalized (e.g., `"123.0"` → `"123"`) to prevent mismatches.

---

## Removed containers

- **Book questions** that belong to any container listed in `containers_to_be_removed.csv` are **omitted** from the output.  
- **Non‑book questions** from those containers are **added** to the candidate pool.  
- Membership checks accept `N`, `N.0`, and numeric forms, and strip BOMs automatically.

## Report processor (optional)

A helper (at the end of `substitutions.py`) converts raw “Questions Reports” CSVs to a clean `processed_questions.csv`, and looks up question IDs by `(page, question)`:

- `process_reports(paths, export_path)` – read raw CSVs, keep only codes starting with `סח-`, parse `page_number` & `question_number`, dedupe/sort, export five columns:  
  `question_id, main_subject, difficulty_level, page_number, question_number`
- `find_question_ids(page, question, paths=None, raw_df=None)` – search raw reports for all `question_id`s at the given page & question.

## Troubleshooting

**A container still shows up although it’s in `containers_to_be_removed.csv`.**  
- Verify the file is UTF‑8 (BOM ok) and values are not quoted with trailing spaces.  
- Headerless files and single values are supported.  
- IDs like `62616.0` are normalized; the loader accepts both `62616` and `62616.0`.  
- Rows for removed containers are filtered from the dataframe before writing.

**I see `62616.0` in output.**  
We normalize container IDs for display; check you’re running the latest code and that Excel isn’t reformatting when opening the CSV.

**EmptyDataError reading a CSV.**  
Loaders handle empty files and return empty sets/frames; verify the path and that the file isn’t locked.
